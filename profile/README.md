## 🧩 Core Development Principles

- 📚 **Learn:** Study established implementations, books, and open-source projects.
- 🔬 **Experiment:** Test hypotheses using historical and live market data.
- 🧪 **Validate:** Apply rigorous backtesting and out-of-sample evaluation.
- 🛡️ **Manage Risk:** Prioritise capital preservation and risk-adjusted returns.
- 🔧 **Build:** Develop independent, modular, reusable trading components.
- 👤 **Human-in-the-Loop:** Retain manual approval before trade execution.

---

## 📂 Repository Guidelines

- 📖 Forked repositories serve as learning and reference material.
- 🧪 Experiments and modifications are maintained separately where appropriate.
- 🏗️ Independent implementations are developed with modular, reusable code.
- 📝 Original authors and sources are credited.
- 🔍 Strategies are evaluated before considering real-money deployment.
